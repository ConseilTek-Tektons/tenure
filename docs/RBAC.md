# Tenure role-based access control

Permissions separate worker visibility, event validation, rule publication, provisioning operations, reconciliation repair, target configuration, audit, and access administration.

Rule owners can preview and publish tested rules but do not operate arbitrary target tasks. Operators execute approved lifecycle work without editing rules. HR partners validate source events without configuring connectors. Target owners approve mappings and repair plans. Auditors read evidence without mutation. Unknown groups receive `viewer`.
